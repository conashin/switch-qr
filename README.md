# Server QR Code Generator

這個命令列工具可以將包含伺服器資訊的 YAML 檔案，轉換為高度最佳化的 QR Code 圖片，非常適合列印成小尺寸貼紙（如 15x15mm）貼在機器上。

## 為什麼產生的 QR Code 這麼小？

為了確保在 15x15mm 的微小尺寸下，手機相機依然能穩定、快速地掃描，本程式實作了以下三種優化：

1.  **JSON 鍵名縮寫 (Minified Keys)**：
    將原本冗長的中文鍵名替換成單一英文字母，大幅降低了儲存在 QR Code 中的文字長度。即使您的「備註」欄位內容很長，也不會因為鍵名過多而讓條碼變得密密麻麻。
2.  **最低容錯率 (EcLevel::L - 7%)**：
    QR Code 的容錯機制是為了修補破損而設計的，但代價是會增加條碼的複雜度。我們改用最低的 `L` 級別，只保留 7% 的修補能力，這讓黑白方塊的數量降到最低，方塊的物理面積因此變得更大、更清晰。
3.  **無留白邊緣 (No Quiet Zone)**：
    一般的 QR Code 產生器會在圖片周圍留下預設的白邊。本工具刻意將白邊移除（`quiet_zone(false)`），這樣當您把圖片等比例縮小印在 15x15mm 的貼紙上時，每一顆黑白方塊的實際可視面積都會被最大化。

## 欄位對應表 (JSON 輸出格式)

掃描 QR Code 後，您會看到如下的 JSON 格式資料。為了解省空間，對應的代號意義如下：

*   `N`: 名稱 (Name)
*   `IP`: IP 位置
*   `DNS`: DNS 名稱
*   `M`: 備註 (Memo / Notes) - 允許填寫大量文字，或為空字串。
*   `Y`: 購入年份 (Purchase Year)
*   `D`: QRCode 建立日期 (程式執行當下自動產生，格式：YYYY-MM-DD)

例如掃描結果可能會是：
```json
{"N":"Server01","IP":"192.168.1.100","DNS":"dns1.example.com","M":"主要資料庫伺服器，需定期備份","Y":"2023","D":"2023-10-25"}
```

## 使用教學

### 1. 準備 YAML 檔案

建立一個包含伺服器資訊的 YAML 檔（例如 `input.yaml`），請注意 `notes` 欄位是可選的，如果不填寫會自動變成空字串：

```yaml
name: "Server01"
ip: "192.168.1.100"
dns: "dns1.example.com"
notes: "備註內容，可以很長，或者整行刪除"
purchase_year: "2023"
```

### 2. 執行程式產生圖片

如果您已經下載了編譯好的執行檔 (例如名為 `app`)，請在命令列中執行：

```bash
./app input.yaml
```

執行成功後，您會在當前目錄下看到一張名為 `Server01.png` 的圖片檔，這就是您的優化版 QR Code。

## GitHub Actions 自動發布

本專案配置了 GitHub Actions CI/CD 流程：
當您推送(Push)一個符合 `v*` 命名規則的標籤 (Tag，例如 `v1.0.0`) 時，系統會自動在雲端編譯出以下四個平台的執行檔，並建立一個 GitHub Release：

*   Windows x86_64
*   Windows arm64
*   Linux x86_64
*   Linux arm64

您可以直接到 Releases 頁面下載符合您系統架構的執行檔。
